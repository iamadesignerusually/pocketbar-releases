# PocketBar

Ein kleines natives Menüleisten-Tool für macOS 26 und Apple Silicon.

[Neueste Testversion herunterladen](https://github.com/iamadesignerusually/pocketbar-releases/releases/latest)

PocketBar zuerst beenden, den PKG-Installer öffnen und die App danach aus Programme starten. Die Bedienungshilfen-Freigabe erteilst du in macOS. Neue Versionen werden anschließend von PocketBar geprüft und auf Wunsch beim Beenden installiert.

Die Testfassungen sind noch nicht notarisiert. macOS kann nach Updates erneut eine Bedienungshilfen-Freigabe verlangen. Das Verhalten mit echten Menüleistensymbolen wird noch praktisch geprüft.

Dieses Repository enthält nur öffentliche Downloads. Die Entwicklung findet getrennt statt. Feed und Update-Archive sind Ed25519-signiert.
